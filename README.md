## How to Explore the Projects

- **SQL projects:** Open the `.sql` files using SQL Server Management Studio or MySQL Workbench, depending on the project.
- **Python project:** Open the Jupyter Notebook using Jupyter Notebook or JupyterLab. Install the required Python libraries before running it.
- **Excel projects:** Open the `.xlsx` files in Microsoft Excel.
- **Power BI project:** Open the `.pbix` file using Power BI Desktop.
- **Tableau dashboards:** Visit the Tableau Public profile linked above.

Some projects require their corresponding datasets and appropriate database setup to run.
